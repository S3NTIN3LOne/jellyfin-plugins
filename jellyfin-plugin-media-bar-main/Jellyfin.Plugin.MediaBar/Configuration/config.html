Media Bar

Hilfe
Media Bar: Legt fest, ob die Media Bar angezeigt wird.
Empfohlen: embedded verwendet die mitgelieferte, zum Plugin passende Version ohne Internetzugriff. Für eine andere Version kann eine konkrete Versionsnummer (z. B. 2.4.12.0) eingetragen werden. Diese wird aus dem Internet geladen.
Lädt bei der Versionsangabe main oder latest den aktuellen Entwicklungsstand aus dem Internet. Änderungen können innerhalb eines halben Tages automatisch erscheinen. Zum Zurückkehren zur mitgelieferten Version diese Option deaktivieren.
Verwendet die Datei avatars/list.txt im Hauptverzeichnis von jellyfin-web als Titelliste.
Name der Wiedergabeliste für die Media Bar, wenn die Titelliste aus Datei deaktiviert ist. Ohne Angabe werden Titel zufällig ausgewählt.
Serverseitige Modi und saisonale Empfehlungen haben Vorrang vor der lokalen Auswahl von Kategorie, Bibliotheken und Anzahl. Wiedergabelisten und list.txt werden dabei nicht verwendet. Nach dem Speichern die App neu starten oder die Seite neu laden.
Halloween: Genre „Horror“ oder Schlagwort „Halloween“. Weihnachten: Schlagwörter oder Genres „Christmas“, „Weihnachten“ oder „Xmas“. Diese Schlagwörter lassen sich im Metadaten-Editor von Jellyfin vergeben. Anzahl, Kategorie und Bibliotheken werden unten festgelegt. „Zuletzt hinzugefügt“ zeigt neueste Titel zuerst; die anderen Modi wählen zufällig aus, auch bereits gesehene Titel. Ohne passende Titel wird keine Media Bar angezeigt. Die Empfehlungen gelten ganzjährig auf allen Geräten; die animierte Girlande erscheint ausschließlich im Weblayout, nicht im TV-Modus oder auf webOS. Die Halloween-Girlande erscheint nur vom 1. bis 31. Oktober, die Weihnachtsgirlande nur vom 1. bis 31. Dezember (lokales Datum des Geräts). Beim Tageswechsel und bei Rückkehr zum Tab wird die Anzeige automatisch aktualisiert.
Maximale Gesamtzahl über alle ausgewählten Bibliotheken in serverseitigen und saisonalen Modi. „Zuletzt hinzugefügt“ berücksichtigt auch gesehene Titel und Titel ohne Logo.
Bei Serien zählt das Hinzufügen der Serie, nicht das Datum ihrer neuesten Folge.
Optional: Bibliotheksnamen, z. B. Filme oder Kinder. Leer bedeutet alle Bibliotheken, auf die der angemeldete Nutzer zugreifen darf. Nicht verfügbare Bibliotheken werden übersprungen. Ohne Treffer wird keine Media Bar angezeigt.
Standard: 50 %. Gilt für das TV-Layout von Jellyfin und LG webOS. Im TV-Modus wird eine kompakte Ansicht ohne Inhaltsbeschreibung verwendet.
Zeit bis zum nächsten Titel in Millisekunden. -1 verwendet den Standardwert.
Wartezeit in Millisekunden nach einer fehlgeschlagenen Initialisierung. -1 verwendet den Standardwert.
Wischstrecke in Pixeln zum Wechseln zum nächsten oder vorherigen Titel. -1 verwendet den Standardwert.
Prüfintervall in Millisekunden für den Ladezustand der Anmeldung und Startseite. -1 verwendet den Standardwert.
Längenbegrenzung der Inhaltsbeschreibung. Der verfügbare Platz und die Zeilenbegrenzung des Layouts bestimmen die sichtbare Länge. -1 verwendet den Standardwert.
-1 verwendet den Standardwert.
-1 verwendet den Standardwert.
Maximale Anzahl geladener Titel bei Nutzerauswahl. Serverseitige und saisonale Modi verwenden das Feld „Anzahl der Titel“. -1 verwendet den Standardwert.
Anzahl der im Voraus geladenen Titel für einen flüssigen Wechsel. -1 verwendet den Standardwert.
Dauer der Überblendung zwischen Titeln in Millisekunden. -1 verwendet den Standardwert.
Aktiviert den langsamen Zoom der Hintergrundbilder. Dies kann auf schwächeren Geräten die Leistung beeinträchtigen.
Spielt verfügbare Trailer innerhalb der Media Bar ab.
Passt den Seitenhintergrund an den aktuellen Titel der Media Bar an.
